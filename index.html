Personal integration

Oura Ring battery alerts, on your terms.

A personal project that monitors Oura Ring battery status using n8n and sends critical alerts to an iPhone through Pushover.

About this project

The integration uses authorized Oura API access to retrieve battery readings and evaluate critical thresholds. This static website provides project information and policies; it does not read ring data or authenticate Oura users.

This is an independent personal project, not affiliated with, endorsed by, or operated by Oura.

Data and access

The intended integration requests access only to Oura data needed for battery monitoring. OAuth credentials and access tokens must never be placed in this public website or source repository.

Contact

Questions about this project can be raised through GitHub Issues. Please do not post personal or sensitive information in public issues.
