Privacy Policy

Oura Battery Monitor is an independent personal-use project under development. This policy describes the current public website and the intended battery-monitoring integration.

Information handled by this website

This static website does not ask for an Oura login, collect ring readings, operate a contact form, or intentionally deploy analytics or advertising cookies. It is hosted through GitHub Pages; GitHub may process technical request information according to its own privacy statement.

Planned Oura API integration

Once authorized by the account holder, the integration accesses ring battery information, potentially including charge percentage, charging state, and measurement timestamp, solely to evaluate battery thresholds and deliver notifications. No Oura health data, such as sleep, heart rate, or location information, is required for that purpose. This website itself does not run the integration.

Storage and sharing

The current website has no application backend or database and does not store Oura data or OAuth tokens. No personal data is sold or shared for advertising. Tokens must not be published to this repository or embedded in the public website. If the project adds backend processing, persistent storage, or additional data types, this policy will be updated before those features are deployed.

Third-party services

GitHub hosts this website. Any eventual Oura connection will be subject to Oura's applicable privacy policies and API terms. Pushover delivers device notifications and follows its own privacy practices.

Control and inquiries

An account holder can decline or revoke Oura API authorization through the controls Oura makes available. For questions, use GitHub Issues, without disclosing private information in a public issue.

Changes

This policy may change as the personal integration is developed. Updates will be published here with a revised effective date.
